# 📁 M365-PowerShell-Scripts

Repositorio central de scripts profesionales de PowerShell diseñados para la administración, automatización y análisis de servicios en Microsoft 365, incluyendo SharePoint Online, Teams, OneDrive y Exchange Online.

---

## 📌 Objetivo

Este repositorio tiene como finalidad ofrecer scripts reutilizables, bien documentados y alineados con buenas prácticas de desarrollo, para facilitar la gestión de entornos Microsoft 365 desde la línea de comandos.

---

## 📂 Estructura del Repositorio

```
M365-PowerShell-Scripts/
├── scripts/            # Scripts organizados por servicio de M365
├── modules/            # Módulos reutilizables de PowerShell (Pendiente)
├── docs/               # Documentación detallada de cada script
├── tests/              # Pruebas automatizadas (pPendiente)
├── .github/            # Workflows para CI/CD y otras automatizaciones (Pendiente)
├── README.md           # Este archivo
├── LICENSE             # Licencia del repositorio
├── .gitignore          # Exclusión de archivos innecesarios
├── CHANGELOG.md        # Historial de cambios
├── CONTRIBUTING.md     # Guía para contribuir
└── CODE_OF_CONDUCT.md  # Código de conducta para la comunidad
```

---

## 🧠 Servicios Cubiertos

- ✅ SharePoint Online  
- ✅ Microsoft Teams  
- ✅ OneDrive for Business  
- ✅ Exchange Online  
- 🔜 Nuevos módulos por venir (Planner, Entra ID, etc.)

---

## 🚀 Cómo Empezar

1. Clona el repositorio:  
   ```bash
   git clone https://github.com/tuusuario/M365-PowerShell-Scripts.git
   ```
2. Revisa los scripts en la carpeta `/scripts/`
3. Consulta la documentación en `/docs/`
4. Ejecuta los scripts desde PowerShell 7+ con permisos adecuados
