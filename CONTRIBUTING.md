# 🤝 Guía para Contribuir

Gracias por tu interés en contribuir a este repositorio de scripts para Microsoft 365. A continuación se detallan algunas normas básicas para colaborar de manera efectiva:

---

## 🛠️ Cómo Contribuir

1. **Fork** este repositorio.
2. Crea una rama para tu funcionalidad (`git checkout -b feature/nueva-funcion`).
3. Realiza tus cambios con buenas prácticas de PowerShell.
4. Asegúrate de que el código esté documentado y probado.
5. Haz un **Pull Request** con una descripción clara.

---

## 🧪 Pruebas

- Si agregas nuevas funcionalidades, crea scripts de prueba en la carpeta `/tests`.
- Utiliza [Pester](https://pester.dev/) si es posible.

---

## 📦 Estilo de Código

- Usa nombres descriptivos para funciones y parámetros.
- Añade cabeceras con `.SYNOPSIS`, `.DESCRIPTION`, `.PARAMETER`, `.EXAMPLE`.
- Sigue la guía oficial: https://github.com/PoshCode/PowerShellPracticeAndStyle

---

## 📝 Documentación

Agrega documentación en la carpeta `/docs` si el cambio lo requiere.

---

¡Gracias por contribuir!
